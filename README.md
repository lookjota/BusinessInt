# Sales Data Analysis + Business Intelligence Dashboard

Two integrated **portfolio projects** built from **synthetic (not real) 2025 sales data**.

## Projects

1. **Sales Data Analysis** — Python, pandas, SQLite/SQL, matplotlib. Generate data, validate, join tables, calculate revenue, analyze by month/category/region and export CSVs.
2. **Sales BI Dashboard** — Streamlit, Plotly. Interactive filters, KPI cards, monthly trend, regional and category comparisons, downloadable filtered dataset. The same processed CSV can be imported into **Power BI Desktop** to recreate the dashboard there.

> The supplied dashboard is implemented in **Streamlit, not Power BI**. Don't claim Power BI project delivery until you've actually recreated it in Power BI.

## Quick start on Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/generate_data.py
python scripts/analyze.py
streamlit run dashboard/app.py
```

The dashboard opens in your browser at the address printed by Streamlit (usually `http://localhost:8501`).

## SQL

```bash
sqlite3 -header -column outputs/sales.sqlite < sql/analysis.sql
```

If the `sqlite3` CLI isn't installed, open `outputs/sales.sqlite` with another SQLite client or Python's built-in `sqlite3` module.

## Data model and business rules

- `customers.csv`: customer_id, customer_name, region
- `products.csv`: product_id, product_name, category, list_price
- `orders.csv`: order_id, date, customer_id, product_id, quantity, unit_price, discount_pct, status
- Revenue = quantity × unit_price × (1 − discount_pct)
- **Only completed orders** contribute to revenue, order counts, customer counts and the dashboard. Cancelled/returned records are excluded rather than treated as refunds.
- One order = one product line in this synthetic dataset.
- BRL values are synthetic and are not actual Brazilian sales results.

## Optional: recreate in Power BI Desktop

Import `outputs/sales_clean.csv` using **Get Data → Text/CSV**. Check that `order_date` is Date and `revenue` is Decimal. Create KPI cards (sum revenue, distinct count order_id, distinct count customer_id, average ticket), line chart by month, bar charts by region/category, and slicers. Use a proper calendar/date table when implementing time intelligence. Power BI Desktop is not natively available on Linux; use a Windows PC or Windows VM if needed.
